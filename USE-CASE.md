# Варіанти використання (Use Cases)

## Актори

| Актор | Опис |
|-------|------|
| **Гість** | Неавтентифікований користувач |
| **Користувач** | Автентифікований користувач (має JWT токен) |
| **Учасник** | Користувач, що є членом конкретного чату |
| **Адмін** | Учасник з роллю ADMIN у чаті |
| **СуперАдмін** | Учасник з роллю SUPER_ADMIN — власник чату, обходить усі перевірки прав |

---

## Модуль Auth

### ВВ-01: Реєстрація
- **Актор**: Гість
- **Endpoint**: `POST /auth/register`
- **Сценарій**: Гість надає email, нікнейм, тег, пароль → система перевіряє унікальність email і тегу → створює користувача з `emailVerified: false` → надсилає OTP-код на пошту
- **Помилки**: 409 email/тег вже зайнятий, 422 невалідний формат email/тегу/нікнейму

### ВВ-02: Вхід
- **Актор**: Гість
- **Endpoint**: `POST /auth/login`
- **Сценарій**: Гість надає email або тег + пароль → система знаходить користувача → перевіряє хеш пароля → перевіряє підтвердження email → повертає JWT токен
- **Помилки**: 401 невірні дані, 403 email не підтверджений

### ВВ-03: Підтвердження email
- **Актор**: Гість
- **Endpoint**: `POST /auth/verify-email`
- **Сценарій**: Гість надає email + OTP → система звіряє код → встановлює `emailVerified: true`, очищає OTP
- **Помилки**: 400 невірний або протермінований OTP

### ВВ-04: Повторне надсилання OTP
- **Актор**: Гість
- **Endpoint**: `POST /auth/resend-otp`
- **Сценарій**: Гість надає email → система генерує новий OTP → надсилає на пошту
- **Помилки**: 404 користувача не знайдено

## Модуль User

### ВВ-05: Отримати власний профіль
- **Актор**: Користувач
- **Endpoint**: `GET /user/me`
- **Сценарій**: Користувач надсилає Bearer токен → система декодує JWT → повертає профіль (без passwordHash та otp)
- **Помилки**: 401 невірний або відсутній токен

---

## Модуль Chat

### ВВ-06: Створити чат
- **Актор**: Користувач
- **Endpoint**: `POST /chat`
- **Сценарій**: Користувач надає назву, тег, опціональний опис → система перевіряє унікальність тегу → створює чат → автоматично створює запис членства з роллю SUPER_ADMIN для творця
- **Помилки**: 409 тег вже зайнятий, 422 невалідний формат назви/тегу/опису

### ВВ-07: Список чатів
- **Актор**: Користувач
- **Endpoint**: `GET /chat?page=1&limit=20`
- **Сценарій**: Повертає пагінований список усіх чатів із загальною кількістю

### ВВ-08: Отримати чат
- **Актор**: Учасник
- **Endpoint**: `GET /chat/:chatId`
- **Guard**: MemberGuard — користувач має бути активним учасником (не заблокованим, не тим що вийшов)
- **Сценарій**: Повертає деталі чату
- **Помилки**: 403 не є учасником / заблокований, 404 чат не знайдено

### ВВ-09: Оновити чат
- **Актор**: Учасник з правом `EDIT_CHAT_INFO`
- **Endpoint**: `PATCH /chat/:chatId`
- **Guard**: MemberGuard з `@RequiresPermission(EDIT_CHAT_INFO)`
- **Сценарій**: Учасник оновлює назву та/або опис (тег незмінний)
- **Помилки**: 403 недостатньо прав

## Модуль Member

### ВВ-10: Додати учасника
- **Актор**: Учасник з правом `ADD_MEMBERS`
- **Endpoint**: `POST /chat/:chatId/members`
- **Сценарій**: Надає userId та опціональну роль/права → система перевіряє існування цільового користувача → якщо раніше вийшов: реактивує запис → інакше створює новий
- **Помилки**: 403 недостатньо прав або роль занадто висока, 404 користувача не знайдено, 409 вже є учасником, 403 цільовий заблокований

### ВВ-11: Вийти з чату
- **Актор**: Учасник
- **Endpoint**: `DELETE /chat/:chatId/members/leave`
- **Сценарій**: Учасник встановлює власний `leftAt` — м'який вихід, запис зберігається для можливого повернення
- **Помилки**: 403 не є учасником

### ВВ-12: Заблокувати учасника
- **Актор**: Учасник з правом `BAN_MEMBERS`
- **Endpoint**: `PATCH /chat/:chatId/members/:memberId/ban`
- **Сценарій**: Встановлює `bannedAt` у цільового учасника. Актор може блокувати лише учасників з нижчим рангом ролі.
- **Помилки**: 403 недостатньо прав або ранг занадто низький

### ВВ-13: Розблокувати учасника
- **Актор**: Учасник з правом `BAN_MEMBERS`
- **Endpoint**: `PATCH /chat/:chatId/members/:memberId/unban`
- **Сценарій**: Очищає `bannedAt` у цільового учасника
- **Помилки**: 403 недостатньо прав або ранг занадто низький

### ВВ-14: Оновити права учасника
- **Актор**: Учасник з правом `EDIT_PERMISSIONS`
- **Endpoint**: `PATCH /chat/:chatId/members/:memberId/permissions`
- **Сценарій**: Перезаписує масив прав цільового учасника. Актор може діяти лише на учасників з нижчим рангом.
- **Помилки**: 403 недостатньо прав або ранг занадто низький

### ВВ-15: Оновити роль учасника
- **Актор**: Учасник з правом `EDIT_PERMISSIONS`
- **Endpoint**: `PATCH /chat/:chatId/members/:memberId/role`
- **Сценарій**: Змінює роль цільового учасника та скидає права до дефолтних для нової ролі. Не можна призначити роль рівну або вищу за власну (крім SUPER_ADMIN).
- **Помилки**: 403 недостатньо прав або роль занадто висока

## Модуль Message

### ВВ-16: Надіслати повідомлення
- **Актор**: Учасник з правом `SEND_MESSAGES`
- **Endpoint**: `POST /chat/:chatId/messages`
- **Сценарій**: Учасник надає текст → фабрика валідує (не порожній, максимум 4000 символів) → створює повідомлення прив'язане до учасника та чату
- **Помилки**: 403 недостатньо прав, 422 порожній або занадто довгий текст

### ВВ-17: Список повідомлень
- **Актор**: Учасник
- **Endpoint**: `GET /chat/:chatId/messages?page=1&limit=20`
- **Сценарій**: Повертає пагінований список повідомлень чату, відсортований від новіших до старіших. М'яко видалені повідомлення виключаються.

### ВВ-18: Видалити повідомлення
- **Актор**: Учасник (власні повідомлення) або Учасник з правом `DELETE_MESSAGES` (будь-яке)
- **Endpoint**: `DELETE /chat/:chatId/messages/:messageId`
- **Сценарій**: Перевіряє належність повідомлення до чату → якщо учасник є автором АБО має право DELETE_MESSAGES → встановлює `deletedAt` (м'яке видалення)
- **Помилки**: 403 не автор і немає права, 404 повідомлення не знайдено або вже видалено

## Довідник прав

| Право | Опис |
|-------|------|
| `SEND_MESSAGES` | Може надсилати повідомлення в чат |
| `DELETE_MESSAGES` | Може видаляти будь-яке повідомлення в чаті |
| `ADD_MEMBERS` | Може додавати нових учасників |
| `BAN_MEMBERS` | Може блокувати та розблоковувати учасників |
| `EDIT_PERMISSIONS` | Може змінювати ролі та права учасників |
| `EDIT_CHAT_INFO` | Може оновлювати назву та опис чату |

## Права за замовчуванням

| Роль | Права за замовчуванням | Може діяти на |
|------|------------------------|---------------|
| `MEMBER` | `SEND_MESSAGES` | — |
| `ADMIN` | Всі крім `EDIT_CHAT_INFO` | Лише MEMBER |
| `SUPER_ADMIN` | Всі (обходить перевірки) | Будь-кого крім себе |
